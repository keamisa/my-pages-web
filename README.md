# Trang creator

Cấu trúc:
- `index.html`: trang chủ (sửa nội dung ở khối `CONFIG` đầu phần `<script>`)
- `firmware/index.html`: trang firmware (sửa dữ liệu ở khối `FIRMWARE`, đặt `SAMPLE = false` khi dùng dữ liệu thật)
- `videos.json`: 3 video mới nhất, trang tự đọc file này
- `img/`: đặt ảnh QR, ảnh hình nền 4K tại đây

Đăng bằng GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).
